# S3 – deploy user permissions

Minimum IAM permissions for the deploy user to **create and delete S3 buckets**, **set bucket options** (e.g. public access block), and **add, view, and delete objects** in buckets created by our CFT.

---

## Mapped CFT

| CFT template | Resources | Permissions used |
|--------------|-----------|-------------------|
| [cft/templates/vasanthtest-bucket.yaml](../../cft/templates/vasanthtest-bucket.yaml) | `AWS::S3::Bucket` with `PublicAccessBlockConfiguration` | `CreateBucket`, `PutBucketPublicAccessBlock`, `GetBucketPublicAccessBlock`; on delete stack: `DeleteBucket`. Listing/view/object actions are for using the bucket after creation. |

When you add more CFT under `cft/templates/` that create S3 buckets, bucket policies, or object operations, list them here and extend the policy if needed.

---

## What this user can do

- **Buckets:** Create bucket, delete bucket, list all buckets, get bucket location, set and get public access block.
- **View buckets:** List bucket contents, get bucket policy, get bucket tags.
- **Objects:** Put object (upload), get object (download), delete object.

---

## Required actions

### Bucket – create, delete, settings

| Action | Purpose |
|--------|--------|
| `CreateBucket` | Create buckets (e.g. via CFT). |
| `DeleteBucket` | Delete buckets (e.g. on stack delete). |
| `ListAllMyBuckets` | List buckets (e.g. in console). |
| `GetBucketLocation` | Required for many bucket operations. |
| `GetBucketPublicAccessBlock`, `PutBucketPublicAccessBlock` | Match CFT (block public access in vasanthtest-bucket.yaml). |

**Resource:** `arn:aws:s3:::*`

### Bucket – view

| Action | Purpose |
|--------|--------|
| `ListBucket` | List objects in a bucket. |
| `GetBucketPolicy`, `GetBucketTagging` | View bucket config. |

**Resource:** `arn:aws:s3:::*`

### Objects

| Action | Purpose |
|--------|--------|
| `PutObject` | Upload (add) objects. |
| `GetObject` | Download (view) objects. |
| `DeleteObject` | Delete objects. |

**Resource:** `arn:aws:s3:::*/*`

## Policy file

**[../iam-policies/s3.json](../iam-policies/s3.json)** – attach this policy to the deploy user for S3 only.

### Optional – restrict to specific buckets

To allow only buckets created by this repo (e.g. names like `vasanthtest-*` or `awslab-*`), replace the S3 resources in the policy:

- Bucket-level: `arn:aws:s3:::vasanthtest-*`, `arn:aws:s3:::awslab-*`
- Object-level: `arn:aws:s3:::vasanthtest-*/*`, `arn:aws:s3:::awslab-*/*`

Update the JSON and re-attach.
